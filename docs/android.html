Bookmark Any Page on Your Phone
Open Chrome or Brave, tap the Three Dots (⋮) at the top right, and tap the Star (⭐) icon to create a bookmark.
2
Edit Bookmark & Paste Script
Tap Edit on the bookmark prompt (or go to ⋮ > Bookmarks > Mobile Bookmarks). Set the name to something short and quick to type like pdf, clear the URL box, and paste the script you copied above into the URL field.
💡
Recommended Bookmark Name: Naming it pdf makes it effortless to trigger later by typing just 3 letters in Chrome's address bar!
3
Search Bookmark Name & Tap Star (⭐) Result
Open your course document on elearning.paruluniversity.ac.in. Tap Chrome's Address Bar at the top, type the name of your bookmark (e.g. pdf), and tap the result with the Star (⭐) icon. The script runs instantly and the PDF downloads directly to your device!
⭐
Important Chrome Rule: Do not open the bookmark from the 3-dots Bookmarks menu. In mobile Chrome, bookmarklet scripts only execute when you type the bookmark's name into the top address bar and select the suggestion with the Star (⭐) icon.
